# Final v0.1.0 validation figures

These supplied final figures are preserved unchanged. See the complete
[DIS and SIDIS/photoproduction report](../../reports/EEEMCal_pi0_calibration_DIS_SIDIS_v0.1.0.pdf)
for selections, support thresholds and detailed interpretation.

- [Coefficient distributions](calibration_coefficient_distribution_DIS_SIDIS.png):
  overlaid DIS and SIDIS/photoproduction coefficients, with each dataset's
  median line in its matching color.
- [Coefficients by crystal](calibration_coefficients_by_crystal_DIS_SIDIS.png):
  overlaid DIS and SIDIS/photoproduction coefficients versus crystal number
  in the saved cell ordering; crystal number is not a detector cellID.
- [Coefficient maps](calibration_coefficient_maps_DIS_SIDIS.png): side-by-side
  detector maps with the same linear coefficient scale and one shared color bar.
- [Photon energies](photon_energy_DIS_SIDIS.png): reconstructed photon energies
  of training pairs inside each dataset's frozen calibration window.
