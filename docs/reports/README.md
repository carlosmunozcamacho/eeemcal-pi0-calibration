# v0.1.0 physics validation report

[EEEMCal π0 calibration: DIS and SIDIS/photoproduction](EEEMCal_pi0_calibration_DIS_SIDIS_v0.1.0.pdf)
is the authoritative validation report associated with software release
**v0.1.0** of `eeemcal-pi0-calibration`.

It studies ePIC EEEMCal π0-based per-crystal gain determination in 18×275 GeV
neutral-current DIS (Q² >1 GeV²) and low-Q² SIDIS/photoproduction
(0 <Q² <1 GeV²), using common relaxed Selection B. It includes deterministic
training/held-out validation, split-sample gain stability and fixed-shower
injected-gain numerical closure. Full reconstruction feedback remains a
subsequent detector-level validation step.

The PDF and [curated figures](../figures/validation/README.md) are supplied
final assets, preserved unchanged. The report is separate from the
[producer numerical regression evidence](../full_regression.md).
